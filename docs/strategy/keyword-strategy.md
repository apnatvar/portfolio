# Keyword strategy

## Research status

This is an intent-led starting map based on the four published specialist services and the current site content. No paid keyword database, search-volume dataset, difficulty score, or conversion data was supplied or checked. Do not label terms as high-volume or low-competition. Validate wording with Search Console, customer language, and a future keyword dataset before expanding.

## Competitive page review (25 October 2026)

These are observations of competitor self-presentations, not independent evaluations. The [MadeByAris Next.js SEO page](https://madebyaris.com/services/nextjs-development/nextjs-seo) presents audits tied to code, App Router metadata, schema, sitemaps, migration redirects, and performance work; it describes a crawl, prioritize, fix, verify workflow. The [Social Animal Next.js consulting page](https://socialanimal.dev/solutions/nextjs-consulting-services/) presents technical audits and implementation support around rendering, crawlability, Core Web Vitals, and code-level diagnosis. [AsyncForge technical SEO development](https://asyncforge.com/services/seo-development/) presents implementation including rendering, structured data, metadata, sitemaps, performance, and reusable content infrastructure.

Across these self-presentations, audits and implementation are common. A possible distinction for AP is focused work for small product teams, with reusable checks and a direct path from diagnosis to implementation. Treat this as a positioning hypothesis to test through conversations and qualified inquiries; do not state it as a proven market advantage.

## Content and measurement

Use one service page per distinct commercial need. Support with practical guides (for example, Next.js metadata, technical audit checklists, page quality, and field-versus-lab performance), each with a clear next-step link. Review Search Console impressions, clicks, query language, and qualified inquiries after sufficient data accrues; do not infer demand from impressions alone.
