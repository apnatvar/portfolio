# Programmatic SEO

## Current site scope

The site has a finite, curated route set for service pages, writing guides, tools, and portfolio items. The route list and sitemap are maintained in code. No large dataset-driven landing-page generator is established as a site capability in this repository.

The Programmatic SEO service describes planning and building page systems; that offer is not evidence that this portfolio itself uses mass page generation or has produced SEO results from it.

## Page eligibility and design

Before adding a template-backed page set:

1. Define the distinct user need each page answers and verify that the source data can support an accurate, useful answer.
2. Define route identity, required fields, validation, internal links, metadata, canonical behavior, and error/empty-data handling.
3. Exclude incomplete, duplicate, stale, or low-value records from publication and the sitemap; provide review and retirement paths.
4. Launch a representative slice and inspect rendered pages, links, data accuracy, indexation signals, and reader feedback before expanding.

Page count is not a success measure. Avoid generating substantially similar pages primarily to target query variants. Google's spam policy calls this scaled content abuse when the purpose is ranking manipulation rather than helping people, regardless of whether content is produced by AI or other methods.
